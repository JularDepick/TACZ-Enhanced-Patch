A Minecraft mod that is an enhancement patch for TACZ. It constrains the original mod's behavior to prevent the combat power system from collapsing, while providing extended gameplay that the original mod lacks.

---

## Requirements

| Item | Requirement |
|:---:|:---:|
| Minecraft | 1.20.1 |
| Mod loader | Forge 47.x |
| Dependency | TACZ 1.1.8 or later |
