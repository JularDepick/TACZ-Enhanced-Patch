一款 Minecraft 模组: 以独立补丁的形式收紧 TACZ 的战斗强度, 让持枪敌对生物成为威胁与补给的主体, 并补上原模组缺失的地面玩法

---

## 前置要求

| 项 | 要求 |
|:---:|:---:|
| Minecraft | 1.20.1 |
| 模组加载器 | Forge 47.4.23 及以上 |
| 上游模组 | TACZ 1.1.8 及以上 |
| Java | 17 及以上, 运行游戏所需 |
| 安装位置 | 客户端与服务端都要安装 |

## 模组内容

### 枪手

| 机制 | 说明 |
|:---:|:---|
| 武装生成 | 敌对生物按难度概率携带 TACZ 枪械, 苦力怕等非人形怪物同样在列, 不新增实体类型 |
| 持械外观 | 非人形生物被武装后, 在原模型之外叠加一具人形骨架并画出主手枪械, 一眼可辨 |
| 受击反击 | 持枪生物被打中后立刻锁定攻击者还击, 可配置为只还击敌对目标, 同族之间不内讧 |
| 临场武装 | 和平, 中立与友军生物被打到配置的阈值血量后按概率抄起随机枪支, 转向攻击伤害来源; 人形与非人形分别配置概率 |
| 弹药与配件 | 每把枪的配件与备弹随机且有限, 弹尽后收起枪械换回原版武器, 给玩家留出反击窗口 |
| 耐久 | 正规枪手按分档提高生命, 四件护甲按部位独立随机抽取皮革到合金材质, 临场武装的生物只拿枪不穿甲 |
| 战利品 | 击杀必定获得同口径弹药, 数量与剩余备弹挂钩, 并有概率获得该枪手使用的枪, 随机配件与高阶口径弹药 |
| 战力与掉落 | 击杀任意持械生物时, 其原版掉落按 一加 持械生物战力除以击杀者战力 放大, 战力取本次战斗的峰值, 上限可配置 |

### 持枪小兵

| 机制 | 说明 |
|:---:|:---|
| 中立生成 | 随遗迹守军生成, 无阵营个体不主动攻击, 被打只会逃跑 |
| 必定持械 | 生成即持有随机枪械, 不受枪手总开关与生物持械配置影响 |
| 补给产出 | 击杀必掉同口径弹药, 并按概率掉落枪械与配件, 另有随机种类与数量的食物与杂物 |
| 外观 | 僵尸村民模型加自绘迷彩贴图, 头部与四肢齐全, 五官完整, 手持枪械可见 |
| 迷彩 | 迷彩绿, 迷彩沙, 迷彩灰与迷彩雪四套贴图, 生成时按个体取一套, 之后不再变化 |
| 守军 | 遗迹守军绑定该遗迹的阵营, 在领地内近战还击, 并会骑乘坦克组成组合体 |
| 属性 | 生命与护甲按游戏难度取值, 为坦克的四分之一, 不读取模组配置 |
### 遗迹

| 机制 | 说明 |
|:---:|:---|
| 建筑蓝图 | 建筑本体是 WorldEdit 的 .schem 文件, 可放模组内置目录或存档服务端配置目录下的 `tacz_enhanced_patch_ruins`, 每次生成随机选一座; 内置只接受 .schem, 外部目录兼容旧版 .schematic; 尺寸上限宽 256 高 128 深 256, 三个方向各自受限 |
| 随区块生成 | 遗迹是原版结构, 由结构集在区块生成阶段选点与写入, 不占服务端 tick; 跨区块的部分随区块生成补齐 |
| 地形适配 | 选址要求中心附近地表高差不超过两格, 海平面及以下不生成; 选址按 34x34 区块的网格划分, 每格最多一座遗迹, 相邻两格的最小间隔为 8 个区块 |
| 中断恢复 | 区块没生成完就不写盘, 崩溃或中途退出后按种子重新生成, 结果一致; 站点数据在区块加载时按结构起点重建 |
| 宝箱与物资箱 | 战利品箱在建筑内部自动寻找有地有顶的空位; 物资箱按概率散布在各层地面, 内容为枪械, 弹药, 护甲与食物, 没有必出项 |
| 旗帜与阵营 | 建筑中心放置原版旗帜, 颜色即阵营, 同色遗迹同阵营, 不同颜色沿用随机合作或敌对 |
| 领地与补兵 | 以旗帜高度为中心、高等于水平直径的圆柱领地, 半径按建筑尺寸自适应; 兵力不足时按固定间隔补兵, 补到触发比例为止 |
| 死遗迹 | 夺旗后的遗迹不再补兵, 不再触发进出与夺旗提示, 也不再生成物资箱; 但仍占据选址网格 |
| 夺旗 | 核心区内玩家在兵力够低时开始倒计时, 离开核心区超过 5 秒才中断, 期间倒计时反向增加; 结束时按兵力判定成败; 开始, 中断, 失败与成功都会给出具体原因与数值; 成功后残余守军转为溃军, 战力按系数下降 |
| 夺旗战利品 | 成功后在核心区生成补给箱, 弹药与武器按击杀累计折算, 另按战绩发放经验 |
| 奖励箱 | 必定给一套同材料护甲与一把剑, 每件五成概率带随强度提升的附魔, 另有末影珍珠, 概率末影之眼与面包 |
| 旗帜纪念品 | 夺旗成功后旗帜可破坏掉落, 名称为 颜色阵营旗帜-(坐标), 悬浮提示记录遗迹坐标与每名参与者的击杀与经验 |
| 遗迹指南针 | 绿宝石与指南针在工作台横向相邻合成, 右键查询最近的遗迹, 提示距离, 坐标, 建筑名与生成状态, 指针始终指向该遗迹; 选址按存档种子预先索引, 因此区块还没生成的遗迹也能查到, 索引随区块加载与查询向外扩展 |
| 兵力读数 | 处于遗迹内部时, 屏幕右上角显示该遗迹剩余兵力百分比, 每 20 tick 刷新, 数值越高越危险, 颜色随之变化 |
| 顶部提示 | 夺旗倒计时在 5 秒之后改为顶部居中的单行提示, 位于方向标尺读数之下, 关闭方向标尺时上移 |

| 机制 | 说明 |
|:---:|:---|
| 单一物品 | 全模组只有一种手雷, 堆叠上限 64; 六项属性随物品数据走, 同一个物品 ID 可以有不同属性 |
| 配色 | 原版十六种旗帜色加四种迷彩, 只改物品染色与界面文案, 循环切换 |
| 三维外观 | 手雷是三维物品模型, 颜色切换只改物品贴图; 投掷物按飞行方向摆正, 转动视角不会跟着转 |
| 蓄力投掷 | 按住右键蓄力, 松开投出; 蓄力三秒封顶, 手持姿态切到拉弓, 视野随蓄力收缩 |
| 初速度 | 在服务端配置的区间内按蓄力比例取值, 默认 4 到 16 格每秒, 可调到 4 到 64 |
| 弹道 | 运动交给原版投掷物逻辑, 重力与阻力用游戏自己的数值, 位置每 tick 同步一次 |
| 粘性 | 开启后第一次碰撞就停住, 撞到方块就地停下, 撞到生物或玩家则跟随其移动直到爆炸 |
| 自适应反弹 | 关闭粘性时按方块硬度决定反弹强弱, 越硬的方块弹得越弱, 法向速度过低即静止 |
| 六项属性 | 手持时用九个固定按键切换引信, 威力, 杀伤对象, 粘性, 特效与颜色; 成对按键到边界即停 |
| 引信 | 从按下右键开始计时, 可设 1 到 10 秒或触发式; 触发式碰到方块或生物立即爆炸, 延时引信到点爆炸 |
| 爆炸 | 威力 0 到 16 对应 0 到 16 格杀伤半径与 0 到 64 点中心伤害, 伤害随距离线性衰减; 杀伤空间是扁球, 竖直半径只有水平的三分之二 |
| 破甲 | 手雷固定破甲四成, 迫击炮炮弹固定破甲六成, 不可调; 破甲部分只跳过护甲点数, 附魔保护仍然生效 |
| 震退 | 位移等于水平半径的一半, 中心最远, 边缘归零, 与杀伤档位无关 |
| 方块破坏 | 威力由内向外线性衰减到一半, 方块硬度不超过衰减后的威力才被破坏 |
| 震退 | 半径内的玩家与生物被固定推开, 位移与杀伤半径一致, 震退本身不造成伤害 |
| 杀伤对象 | 七档组合: 仅地形, 仅玩家, 仅生物, 排除地形, 排除玩家, 排除生物, 所有 |
| 面板与倒计时 | 屏幕右侧列出手雷, 引信, 威力, 杀伤, 粘性, 特效与颜色; 投出后显示最新一颗的剩余引信 |
| 合成 | 工作台内四角铁锭, 十字火药, 中心线, 一次出四个 |

## 玩法要点

- 枪手弹药有限, 逼它换弹或打空是主要战术
- 被枪手打中会让它立刻还击, 偷袭失败后最好马上换位置
- 打和平生物前想清楚: 半血以下可能抄枪反击, 概率与触发阈值都在配置里
- 高阶枪械稀有且更耐打, 穿甲弹与爆头是快速解决的办法
- 遗迹守卫由补兵持续产生, 先清守卫再搜宝箱最稳; 物资箱散落在各层地面, 顺路翻找收益更高
- 手雷的杀伤对象可以只炸地形或只炸玩家, 狭窄地形里先想好档位再投
- 关闭枪手总开关后所有行为回到原版, 存档结构不变

## 配置

服务端参数全部由存档创建者掌握, 在界面上调整后立即写盘; 客户端只保留自动换弹与枪击来源提示这类本机偏好. 运行期文件位置与参数清单见 [开发者文档](./docs/developer/README.md)

## 兼容性

- 需要 1.20.1 与 Forge 47.x, 上游模组至少 TACZ 1.1.8
- 只通过 TACZ 公开 API 与事件交互, 不修改其源码, 不注入 Mixin
- 关闭或卸载模组后存档仍可正常加载, 枪手标记只记录在实体持久化数据里
- 与刷怪类模组共存, 只读取生成事件并装备主手, 不改变其他模组的生成判定
