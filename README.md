一款 Minecraft 模组: 以独立补丁的形式收紧 TACZ 的战斗强度, 让持枪敌对生物成为威胁与补给的主体, 并补上原模组缺失的地面玩法

---

## 前置要求

| 项 | 要求 |
|:---:|:---:|
| Minecraft | 1.20.1 |
| 模组加载器 | Forge 47.4.23 及以上 |
| 上游模组 | TACZ 1.1.8 及以上 |
| Java | 17 及以上, 运行游戏所需 |
| 安装位置 | 客户端与服务端都要安装 |

## 模组内容

### 枪手

| 机制 | 说明 |
|:---:|:---|
| 武装生成 | 敌对生物按难度概率携带 TACZ 枪械, 苦力怕等非人形怪物同样在列, 不新增实体类型 |
| 持械外观 | 非人形生物被武装后, 在原模型之外叠加一具人形骨架并画出主手枪械, 一眼可辨 |
| 受击反击 | 持枪生物被打中后立刻锁定攻击者还击, 可配置为只还击敌对目标, 同族之间不内讧 |
| 临场武装 | 和平, 中立与友军生物被打到配置的阈值血量后按概率抄起随机枪支, 转向攻击伤害来源; 人形与非人形分别配置概率 |
| 弹药与配件 | 每把枪的配件与备弹随机且有限, 弹尽后收起枪械换回原版武器, 给玩家留出反击窗口 |
| 耐久 | 正规枪手按分档提高生命, 四件护甲按部位独立随机抽取皮革到合金材质, 临场武装的生物只拿枪不穿甲 |
| 战利品 | 击杀必定获得同口径弹药, 数量与剩余备弹挂钩, 并有概率获得该枪手使用的枪, 随机配件与高阶口径弹药 |
| 战力与掉落 | 击杀任意持械生物时, 其原版掉落按 一加 持械生物战力除以击杀者战力 放大, 战力取本次战斗的峰值, 上限可配置 |

### 持枪小兵

| 机制 | 说明 |
|:---:|:---|
| 中立生成 | 随遗迹守军生成, 无阵营个体不主动攻击, 被打只会逃跑 |
| 必定持械 | 生成即持有随机枪械, 不受枪手总开关与生物持械配置影响 |
| 补给产出 | 击杀必掉同口径弹药, 并按概率掉落枪械与配件, 另有随机种类与数量的食物与杂物 |
| 外观 | 僵尸村民模型加自绘迷彩贴图, 头部与四肢齐全, 五官完整, 手持枪械可见 |
| 守军 | 遗迹守军绑定该遗迹的阵营, 在领地内近战还击, 并会骑乘坦克组成组合体 |
| 属性 | 生命与护甲按游戏难度取值, 为坦克的四分之一, 不读取模组配置 |
### 遗迹

| 机制 | 说明 |
|:---:|:---|
| 建筑蓝图 | 建筑本体是 WorldEdit 的 .schem 文件, 可放模组内置目录或存档服务端配置目录下的 `tacz_enhanced_patch_ruins`, 每次生成随机选一座; 内置只接受 .schem, 外部目录兼容旧版 .schematic |
| 分帧粘贴 | 建筑按区块分帧落地, 底面以下补齐石头系地基, 建筑在玩家靠近时逐步出现 |
| 地形适配 | 选址要求中心附近地表高差不超过两格, 海平面及以下不生成; 与已有遗迹的直线距离不小于配置值, 默认 640 格 |
| 宝箱与物资箱 | 战利品箱在建筑内部自动寻找有地有顶的空位; 物资箱按概率散布在各层地面, 内容为枪械, 弹药, 护甲与食物, 没有必出项 |
| 旗帜与阵营 | 建筑中心放置原版旗帜, 颜色即阵营, 同色遗迹同阵营, 不同颜色沿用随机合作或敌对 |
| 领地与补兵 | 以旗帜高度为中心、高等于水平直径的圆柱领地, 半径按建筑尺寸自适应; 兵力不足时按固定间隔补兵, 补到触发比例为止 |
| 夺旗 | 核心区内玩家在兵力够低时开始倒计时, 离开核心区中断, 结束时按兵力判定成败; 开始, 中断, 失败与成功都会给出具体原因与数值; 成功后残余守军转为溃军, 战力按系数下降 |
| 夺旗战利品 | 成功后在核心区生成补给箱, 弹药与武器按击杀累计折算, 另按战绩发放经验 |
| 奖励箱 | 必定给一套同材料护甲与一把剑, 每件五成概率带随强度提升的附魔, 另有末影珍珠, 概率末影之眼与面包 |
| 旗帜纪念品 | 夺旗成功后旗帜可破坏掉落, 名称为 颜色阵营旗帜-(坐标), 悬浮提示记录遗迹坐标与每名参与者的击杀与经验 |
| 遗迹指南针 | 绿宝石与指南针在工作台横向相邻合成, 右键记录最近的遗迹并提示距离, 方向与方位角, 指针始终指向该遗迹 |
| 兵力读数 | 处于遗迹内部时, 屏幕右上角显示该遗迹剩余兵力百分比, 每 20 tick 刷新, 数值越高越危险, 颜色随之变化 |

### 坦克精英怪

| 机制 | 说明 |
|:---:|:---|
| 精英炮击 | 稀有生成的坦克外观怪物, 有阵营时守卫领地, 无阵营时只在受击后还击, 周期性开炮且爆炸范围与伤害远大于恶魂火球 |
| 威压体型 | 碰撞箱 3.4 x 2.4 格, 履带贴地车体炮塔依次向上的自定义模型, 免疫火焰且满击退抗性 |
| 战利品 | 击杀掉落铁锭, 铜锭与火药, 开炮冷却与开炮距离可配置, 生命与威力按难度预设 |
| 组合体 | 肩部最多承载四名小兵, 成员共享按内部生命上限计算的生命与护甲加成, 有阵营坦克死亡后会以无阵营形态复活, 深度上限三次 |
| 玩家驾驶 | 无阵营坦克可以骑乘, 准星控制朝向, WASD 移动, 空格开炮 |
### 中立持械村民

| 机制 | 说明 |
|:---:|:---|
| 生成 | 村民生成时按概率持械, 默认五成, 自然生成与繁殖与治愈都算, 流浪商人不纳入 |
| 立场 | 不主动攻击任何生物; 玩家把生命值打到阈值以下才反击, 受生物攻击时低于九成生命立即反击 |
| 交易 | 沿用原版交易页, 绿宝石结算; 商品取自持有的枪械与弹药, 总量为持有量的两倍 |
| 折扣 | 背包售罄后剩余额度五折, 由系统兜底提供 |
| 退化 | 背包清空即退化为原版村民, 五折额度随之作废 |

### 快速扩容弹匣

| 机制 | 说明 |
|:---:|:---|

| 换弹加速 | 换弹时长 = 原时长 × 缺失弹药比例 × 50%, 40% 或 30%, 分别对应弹药容量 III 到 I, 动画同步加速 |

### 补丁物品页与无限弹匣

| 机制 | 说明 |
|:---:|:---|
| 补丁物品页 | 创造模式新增 TACZ 增强补丁物品页, 集中存放零散物品与生物刷怪蛋 |
| 无限弹匣 | 以上游 III 级扩容弹匣为基底, 继承其图标与属性, 装配后开火与换弹不消耗弹匣与背包弹药, 容量以正无穷符号标注 |

| 方向标尺 | 紧贴屏幕上边界显示横向方位标尺, 宽度占屏幕宽度九成, 标注基本方向与角度数值, 随视角滚动, 默认关闭 |

|:---:|:---|

## 玩法要点

- 枪手弹药有限, 逼它换弹或打空是主要战术
- 被枪手打中会让它立刻还击, 偷袭失败后最好马上换位置
- 打和平生物前想清楚: 半血以下可能抄枪反击, 概率与触发阈值都在配置里
- 高阶枪械稀有且更耐打, 穿甲弹与爆头是快速解决的办法
- 遗迹守卫由补兵持续产生, 先清守卫再搜宝箱最稳; 物资箱散落在各层地面, 顺路翻找收益更高
- 关闭枪手总开关后所有行为回到原版, 存档结构不变

## 配置

服务端参数全部由存档创建者掌握, 在界面上调整后立即写盘; 客户端只保留自动换弹与枪击来源提示这类本机偏好. 运行期文件位置与参数清单见 [开发者文档](./docs/developer/README.md)

## 兼容性

- 需要 1.20.1 与 Forge 47.x, 上游模组至少 TACZ 1.1.8
- 只通过 TACZ 公开 API 与事件交互, 不修改其源码, 不注入 Mixin
- 关闭或卸载模组后存档仍可正常加载, 枪手标记只记录在实体持久化数据里
- 与刷怪类模组共存, 只读取生成事件并装备主手, 不改变其他模组的生成判定
