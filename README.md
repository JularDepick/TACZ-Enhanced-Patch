一款 Minecraft 模组,是 TACZ 模组的增强补丁。它约束了原始模组的行为以防止战斗力量系统崩溃,同时提供原始模组所缺乏的延伸玩法。

---

## 玩法特性

- 原版敌对生物会按难度概率携带 TACZ 枪械, 使用真实弹道与真实换弹流程
- 枪手弹药有限, 弹尽后转入近战, 给玩家反击与撤退的窗口
- 击杀枪手掉落对应口径弹药, 并有概率掉落枪械与随机配件, 支撑以战养战
- 野外生成废弃前哨遗迹, 由守卫镇守, 宝箱提供弹药, 配件与基础物资
- 锁敌范围, 命中准度, 伤害与掉落等参数可在模组列表的配置界面直接调整
- 生成概率, 反应速度, 瞄准误差与伤害倍率均可配置, 关闭开关后恢复原版体验

## 前置要求

| 项 | 要求 |
|:---:|:---:|
| Minecraft | 1.20.1 |
| 模组加载器 | Forge 47.x |
| 前置模组 | TACZ 1.1.8 及以上 |
