# 遗迹系统

遗迹为战斗循环提供物资补给点, 由守卫守护, 让玩家不必长期采集资源

## 组成

| 模块 | 文件 | 职责 |
|:---:|:---:|:---:|
| 结构生成 | `src/main/java/com/taczenhancedpatch/world/RuinedOutpostFeature.java` | 在平地上生成废弃前哨, 放置石砖地基, 残墙, 宝箱与刷怪笼 |
| 特性注册 | `src/main/java/com/taczenhancedpatch/world/ModFeatures.java` | 向 Forge 注册 `ruined_outpost` 特性 |
| 放置规则 | `src/main/resources/data/tacz_enhanced_patch/worldgen/placed_feature/ruined_outpost.json` | 稀有度, 方形分布与地表高度 |
| 配置特性 | `src/main/resources/data/tacz_enhanced_patch/worldgen/configured_feature/ruined_outpost.json` | 绑定特性类型 |
| 群系注入 | `src/main/resources/data/tacz_enhanced_patch/forge/biome_modifier/add_ruined_outpost.json` | 注入全部主世界群系的地表结构阶段 |
| 战利品 | `src/main/resources/data/tacz_enhanced_patch/loot_tables/chests/ruined_outpost.json` | 弹药, 配件与基础物资 |

## 生成规则

- 地形必须相对平整: 以原点为中心 11x11 范围内的地表高度相差不超过 1 格, 且地表方块为实心; 低处用泥土补平, 高处削平
- 海平面以下不生成, 避免水下遗迹
- 地基整体替换为石砖系方块, 墙体带有随机缺口表现坍塌
- 南北两侧留出两格高的门洞, 四角为四格高立柱
- 中央放置宝箱, 北侧放置僵尸刷怪笼

## 守卫与经济

- 刷怪笼产出的僵尸由枪手系统接管, 在 `gunner.spawnerGunnerChance` 概率下持枪
- 宝箱战利品按 2 到 3 组弹药, 1 组随机 TACZ 配件, 2 到 3 组基础物资生成
- 弹药池覆盖 9mm, 45acp, 556x45, 762x39, 12g 与 308, 数量区间按口径区分
- 配件池覆盖红点, 倍镜, 握把, 消音器, 扩容弹匣, 激光与枪托

## 配置项

| 配置项 | 默认值 | 说明 |
|:---:|:---:|:---:|
| `worldgen.ruinsEnabled` | `true` | 是否生成废弃前哨遗迹 |

## 扩展方式

- 新增遗迹类型: 在 `world/ModFeatures` 注册新特性, 并补充对应的 configured_feature 与 placed_feature JSON
- 调整出现频率: 修改 placed_feature 中 `rarity_filter` 的 `chance`, 数值越大越稀有
- 调整战利品: 修改战利品表的 pools 与权重, 新增 TACZ 物品时注意 `AmmoId` 与 `AttachmentId` 两个 NBT 键
- 守卫强度: 由枪手系统的分档权重与 `spawnerGunnerChance` 共同决定

## 已知限制

| 限制 | 说明 |
|:---:|:---:|
| 地形要求 | 严格平整度要求会降低遗迹密度, 山地与水域不生成 |
| 结构体积 | 遗迹为单区块附近的固定尺寸结构, 不含地下空间 |
| 刷怪笼 | 刷怪笼在亮度与距离满足条件前不会产怪 |
