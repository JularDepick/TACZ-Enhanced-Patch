一款 Minecraft 模组: 以独立补丁的形式收紧 TACZ 的战斗强度, 让持枪敌对生物成为威胁与补给的主体, 并补上原模组缺失的地面玩法

---

## 前置要求

| 项 | 要求 |
|:---:|:---:|
| Minecraft | 1.20.1 |
| 模组加载器 | Forge 47.4.23 及以上 |
| 上游模组 | TACZ 1.1.8 及以上 |
| 安装位置 | 客户端与服务端都要安装 |

## 模组内容

### 枪手

| 机制 | 说明 |
|:---:|:---|
| 武装生成 | 敌对生物按难度概率携带 TACZ 枪械, 不新增实体类型, 沿用原版的索敌与掉落骨架 |
| 受击反击 | 持枪生物被打中后立刻锁定攻击者还击, 攻击者超出锁定范围则放弃追击 |
| 临场武装 | 和平, 中立与友军生物被打到半血后按概率抄起随机枪支, 转向攻击伤害来源 |
| 弹药与配件 | 每把枪的配件与备弹随机且有限, 弹尽后转入近战, 给玩家留出反击窗口 |
| 耐久 | 正规枪手按分档提高生命并穿戴皮革到铁质的护甲, 临场武装的生物只拿枪不穿甲 |
| 战利品 | 击杀后掉落同口径弹药, 小概率掉落该枪手实际使用的那把枪与随机配件 |

### 遗迹

| 机制 | 说明 |
|:---:|:---|
| 废弃前哨 | 野外生成 11 格见方的坍塌据点, 中央宝箱提供弹药与配件, 刷怪笼产出守卫 |
| 地形适配 | 对范围内高差有要求, 低洼补平高处削平, 海平面及以下不生成 |

### 配置与权限

| 项 | 说明 |
|:---:|:---|
| 客户端配置 | 自动换弹等本机偏好, 每名玩家各自保存 |
| 服务端配置 | 枪手, 耐久, 掉落与遗迹共 27 项参数, 由服务端同步给客户端 |
| 配置界面 | 客户端分区人人可改; 服务端分区只对存档创建者显示, 普通客户端看不到 |

## 玩法要点

- 枪手弹药有限, 逼它换弹或打空是主要战术
- 被枪手打中会让它立刻还击, 偷袭失败后最好马上换位置
- 打和平生物前想清楚: 半血以下可能抄枪反击, 概率与触发阈值都在配置里
- 高阶枪械稀有且更耐打, 穿甲弹与爆头是快速解决的办法
- 遗迹守卫由刷怪笼与枪手系统联动产生, 先清守卫再搜宝箱最稳
- 关闭枪手总开关后所有行为回到原版, 存档结构不变

## 配置

服务端参数全部由存档创建者掌握, 在界面上调整后立即写盘; 客户端只保留自动换弹这一项本机偏好. 运行期文件位置与参数清单见 [开发者文档](./docs/developer/README.md)

## 兼容性

- 需要 1.20.1 与 Forge 47.x, 上游模组至少 TACZ 1.1.8
- 只通过 TACZ 公开 API 与事件交互, 不修改其源码, 不注入 Mixin
- 关闭或卸载模组后存档仍可正常加载, 枪手标记只记录在实体持久化数据里
- 与刷怪类模组共存, 只读取生成事件并装备主手, 不改变其他模组的生成判定
