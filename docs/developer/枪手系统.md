# 枪手系统

本模组让原版敌对生物持枪, 用真实弹药与经济闭环修复 TACZ 战力失衡与弹药短缺的问题

## 系统组成

| 模块 | 文件 | 职责 |
|:---:|:---:|:---:|
| 生成 | `src/main/java/com/taczenhancedpatch/gunner/GunnerSpawnHandler.java` | 在生物生成收尾阶段按白名单与概率装备枪械 |
| 战斗 | `src/main/java/com/taczenhancedpatch/gunner/GunnerCombat.java` | 索敌, 瞄准, 点射节奏, 换弹与弹尽断火 |
| 军械库 | `src/main/java/com/taczenhancedpatch/gunner/GunnerArsenal.java` | 枪械与口径映射, 备弹量, 掉落区间, 权重分档 |
| 标记 | `src/main/java/com/taczenhancedpatch/gunner/GunnerMarker.java` | 枪手身份与掉落信息写入实体持久化 NBT |
| 战利品 | `src/main/java/com/taczenhancedpatch/loot/BattleLootHandler.java` | 击杀枪手掉落弹药, 枪械与随机配件 |
| 平衡 | `src/main/java/com/taczenhancedpatch/balance/GunDamageBalanceHandler.java` | 缩放枪手子弹伤害与爆头倍率 |
| 接入 | `src/main/java/com/taczenhancedpatch/integration/TaczApi.java` | 唯一的 TACZ 类型入口, 对外暴露 FireMode 与 ShotOutcome 抽象 |

## 运行流程

1. 敌对生物在 `MobSpawnEvent.FinalizeSpawn` 阶段按白名单, 维度黑名单与概率判定是否成为枪手
2. 判定通过后按权重抽取枪械分档, 从对应分档的军械库抽取具体枪械
3. 枪械以虚拟备弹(GunItemBuilder 构建后写入 DummyAmmo)形式装备到主手, 同时写入枪手标记
4. 第一个服务端 tick 调用 `TaczApi.initOperator`, 建立 TACZ 的射击状态与配件属性缓存
5. 后续 tick 执行索敌与开火: 视线判定, 反应延迟, 依据目标胸部位置计算俯仰角与偏航角并叠加瞄准误差
6. 弹匣打空时调用 TACZ 的换弹逻辑, 从虚拟备弹补弹, 虚拟备弹耗尽后停止射击, 交回原版近战 AI
7. 死亡时由 `LivingDropsEvent` 发放对应口径弹药, 少量枪械与随机配件

## 平衡阀门

| 阀门 | 作用 |
|:---:|:---:|
| 虚拟备弹总量 | 枪手无法无限开火, 弹尽后失去压制力 |
| 反应延迟 | 给玩家进入掩体或反击的时间窗口 |
| 点射与停火 | 避免全自动压制变成连续伤害 |
| 瞄准误差 | 降低远距离命中率, 保留走位价值 |
| 伤害倍率 | 抵消 TACZ 原始伤害面向玩家对怪物设计带来的溢出 |
| 分档权重 | 让低阶枪械为主, 高阶枪械稀有 |

## 配置项

配置文件为 `config/tacz_enhanced_patch-common.toml`

| 配置项 | 默认值 | 说明 |
|:---:|:---:|:---:|
| `debugEvents` | `false` | 输出 TACZ 事件与枪手调试日志 |
| `gunner.enabled` | `true` | 枪手系统总开关 |
| `gunner.spawnChance` | `0.2` | 单个敌对生物成为枪手的基础概率 |
| `gunner.difficultyScaling` | `true` | 按难度缩放生成概率与分档权重 |
| `gunner.mobWhitelist` | 僵尸, 尸壳, 溺尸, 骷髅, 流浪者, 掠夺者, 卫道士, 僵尸猪灵, 猪灵蛮兵 | 允许成为枪手的实体列表 |
| `gunner.dimensionBlacklist` | 空 | 禁止出现枪手的维度列表 |
| `gunner.tierWeightLow` | `60` | 低阶枪械权重 |
| `gunner.tierWeightMid` | `30` | 中阶枪械权重 |
| `gunner.tierWeightHigh` | `10` | 高阶枪械权重 |
| `gunner.fireRange` | `28.0` | 开火距离, 单位方块 |
| `gunner.reactionTicksMin` `Max` | `15` `45` | 发现目标后的反应时间区间 |
| `gunner.burstMin` `Max` | `3` `6` | 单次点射发数区间 |
| `gunner.burstPauseMin` `Max` | `8` `24` | 两次点射之间的停火时间区间 |
| `gunner.aimErrorDegrees` | `4.0` | 瞄准误差标准差, 单位角度 |
| `gunner.damageMultiplier` | `0.6` | 枪手子弹伤害倍率 |
| `gunner.ammoDropChance` | `1.0` | 弹药掉落概率 |
| `gunner.ammoDropMultiplier` | `1.0` | 弹药掉落数量倍率 |
| `gunner.gunDropChance` | `0.08` | 枪械掉落概率 |
| `gunner.attachmentDropChance` | `0.08` | 随机配件掉落概率 |

## 扩展方式

- 新增可用枪械: 在 `GunnerArsenal` 的静态块中调用 `register`, 口径必须与 TACZ 该枪的 `ammo` 字段一致
- 新增可持枪生物: 修改配置项的 `gunner.mobWhitelist`
- 新增敌对生物类型: 沿用原版实体 + 枪手标记的方式, 不要新增实体类型, 避免与原版生成逻辑冲突
- 调整平衡: 优先改 `GunnerArsenal` 的分档与备弹量, 其次改配置项

## 已知限制

| 限制 | 说明 |
|:---:|:---:|
| 动作表现 | 生物没有 TACZ 的开火动画, 只有真实弹道与枪声 |
| 误伤 | TACZ 子弹不区分阵营, 枪手可能击中同伴 |
| 持枪显示 | 生物手持枪械的第三人称渲染取决于 TACZ 的物品渲染器, 需要实机验证 |
| 数据依赖 | 枪械与口径映射是静态常量, 前置模组换枪包后需要同步更新 |
